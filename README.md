# Корпоративный портал 

**Корпоративный портал** — веб-сервис компании, реализующий единую точку
входа для сотрудников: новости компании, справочник сотрудников, личный
профиль и систему заявок (на отпуск/больничный и на изменение личных
данных) с согласованием по иерархии подчиненности. Приложение построено
как монолитное веб-приложение с разделением на клиентскую и серверную
части, взаимодействующие через REST API.

**Технологический стек**:
- Backend: Python
- Frontend: React
- База данных: PostgreSQL
- Протокол взаимодействия клиент-сервер: REST API
